8. Implementation Status and Results / Expected Results

8.1 Current Implementation Status and Verified Milestones

The implementation of the IntelliTwin research framework is structured around a modular, reproducible Python codebase residing in src/intellitwin/ [1]–[3]. In strict compliance with pre-registered confirmatory research standards (Architecture Decision Records ADR-018 and ADR-022), all primary algorithmic subsystems, base model checkpoints, conformal calibration engines, maintenance simulation routines, and digital twin replay interfaces have been fully engineered, validated, and frozen prior to held-out test evaluation [4], [7], [9].

The implemented software architecture comprises seven fully integrated functional modules, supported by a comprehensive automated test suite spanning 37 unit and integration test modules:

  1. Data Ingestion and Anti-Leakage Preprocessing Subsystem (src/intellitwin/data/): Implements automated ingestion pipelines for the NASA Commercial Modular Aero-Propulsion System Simulation (C-MAPSS) corpus [1]. Performs systematic feature qualification by pruning six uninformative sensor channels displaying zero variance or rank correlation (Sdropped = {s1, s5, s6, s10, s16, s19}), retaining d = 17 informative operational channels. Enforces training-only Z-score standardization (μtrain, σtrain, computed with ddof=0), K = 6 K-means regime clustering on standardized flight settings, and causal sliding lookback windowing (W = 30 cycles, stride 1, zero-padding prohibited) [1], [10].
  2. Prognostic Base Estimator Subsystem (src/intellitwin/models/): Houses two complementary model families: (i) multi-quantile HistGradientBoostingRegressor (GBR) operating on flattened 510-dimensional causal vectors, minimizing pinball loss across quantiles ρ ∈ {0.05, 0.50, 0.95}; and (ii) PyTorch deep Bidirectional LSTM processing sequential matrices Xi(t) ∈ ℝ30 × 17 with two recurrent layers (h = 64), variational dropout (p = 0.20), and AdamW optimization [3], [4]. A full 30-checkpoint benchmark matrix (3 sub-corpora × 2 architectures × 5 frozen seeds [2026, 2027, 2028, 2029, 2030]) has been trained, verified, and frozen under ADR-020.
  3. Hierarchical Conformal Calibration Subsystem (src/intellitwin/uncertainty/): Formulates exact rational nonconformity quantile solvers addressing cluster non-exchangeability across engines with variable trajectory lengths [9]. Implements asymmetric decision-aware nonconformity scoring parameterized by scaling exponent γ ∈ {0, 1, 2} and asymmetry coefficient β ∈ ℝ:
    σ(p̂) = (1 + p̂ / 125.0)γ,   z(p̂) = exp(−p̂ / 20.0)
    a(p̂) = σ(p̂) · exp(β · z(p̂)),   b(p̂) = σ(p̂) · exp(−β · z(p̂))
    si(t) = max( (p̂i(t) − yi(t)) / a(p̂i(t)),   (yi(t) − p̂i(t)) / b(p̂i(t)),   0 )
    Calibration quantiles place finite probability mass m / (m + 1) with point-at-infinity mass 1 / (m + 1), targeting nominal 1 − α = 0.90 coverage with automatic global fallback routing for regime clusters containing fewer than mg ≥ 10 calibration units [9].
  4. Sequential Decision and Maintenance Simulator (src/intellitwin/simulator/): Implements cycle-by-cycle discrete-event asset lifecycle simulation [5], [8]. Evaluates dynamic stopping times τi = inf{t ≥ W : Li(t) ≤ 1.0} governed by lower conformal bounds, tracks economic lifecycle expenditures under the primary reference scenario in Standardized Cost Units (CPM = 1.0, CFAIL = 5.0, CWASTE = 0.20 SCU per cycle), and logs intervention events [5], [8].
  5. Controlled Attribution and Baseline Protocol (src/intellitwin/decision/): Parameterizes four frozen matched-conservatism control configurations across three families (δ-widened intervals, Δ-safety margins, and θ-earlier intervention thresholds) to disambiguate genuine uncertainty calibration from heuristic over-conservatism [8], [12].
  6. Confirmatory Statistical Inference Engine (src/intellitwin/evaluation/): Executes 10,000 stratified engine-cluster bootstrap resamples with replacement (using PCG64 PRNG), enforces Bonferroni family-wise error rate control (αtest = 0.0125, 98.75% decision intervals), and evaluates Intersection-Union Testing (IUT) decision rules across all 152 pre-registered hypothesis components [12].
  7. Digital Twin Replay Engine and Operator Dashboard (src/intellitwin/twin/, apps/twin_dashboard/): Implements an ISO 23247-aligned state replication engine (TwinReplayEngine) managing a 4-state lifecycle machine (WARMING_UP, ACTIVE, MAINTAINED, FAILED) [14]. Guarantees strict numerical verification parity (atol ≤ 10−4) against offline batch execution, exposed via a modular FastAPI service at port 8000 and an interactive HTML5/JavaScript dashboard [2], [13].

Scientific Demarcation Statement

In strict accordance with confirmatory empirical protocols, the validation metrics in Table 8.3 represent development partition performance. Held-out test trajectories (122 engines across FD001, FD002, FD004) remain strictly blinded prior to official confirmatory execution. Development validation success confirms the numerical stability and convergence of the base models, but does not constitute confirmatory evidence of maintenance cost superiority, subgroup reliability, or cross-condition generalizability.

Expected Confirmatory Experimental Outcomes

Based on the validated mathematical formulation and development experiments, the expected empirical outcomes on held-out test partitions are specified as follows:

  • Expected Outcome for RQ1 (Maintenance Utility): The proposed condition-adaptive conformal calibration method (decision_aware_hcp) is expected to achieve a statistically significant reduction in average fleet lifecycle maintenance cost exceeding 0.20 Standardized Cost Units (Δcost > 0.20 SCU) relative to standard global conformal prediction and uncalibrated point-prediction baselines, while strictly preserving marginal prediction interval coverage error within 5% (E = |(1−α) − PICP| < 0.05) without increasing observed in-service failure rates (Δfail ≤ 0) [5], [7], [8].
  • Expected Outcome for RQ2 (Subgroup Conditional Reliability): Condition-adaptive regime and wear-stage partitioning is expected to eliminate severe localized undercoverage vulnerabilities observed in global conformal calibration. Specifically, worst-group coverage error is expected to improve by at least 1 percentage point (Δerror > 0.01) across the six operational flight regimes (C1–C6) and three lifecycle wear stages (Early, Mid, Late), maintaining all subgroup errors within 5% (E(g) < 0.05) without inducing excessive interval width inflation (Dwidth < 1.0 cycle) [4], [10].
  • Expected Outcome for RQ3 (Decision-Value Attribution): The proposed method is expected to maintain statistically significant cost superiority (Δcost > 0.20 SCU) when contrasted against all three matched-conservatism control families (uniformly widened intervals, point safety margins, and earlier scheduled overhaul thresholds), establishing that operational savings stem from genuine risk-directed uncertainty quantification rather than arbitrary early intervention [8], [12].
  • Expected Outcome for RQ4 (Cross-Condition Generalization and Non-Harm): Across the complete 6-cell evaluation matrix (FD001, FD002, FD004 × GBR, LSTM), the weighted aggregate contrast is expected to demonstrate simultaneous cost reduction (Δ̄cost > 0.20 SCU) and reliability improvement (Δ̄error > 0.01). Concurrently, Two One-Sided Tests (TOST) are expected to establish non-harm in every individual evaluation cell (Lower 98.75% CI of Δcost ≥ −0.20 SCU, Δerror ≥ −0.01) under strict Bonferroni family-wise error rate control (α = 0.0125) [12].
