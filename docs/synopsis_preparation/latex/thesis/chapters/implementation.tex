\chapter{Software Architecture and Implementation}
\label{chap:implementation}

\section{System Architecture and Package Structure}
The IntelliTwin framework is implemented as a modular Python package (\texttt{intellitwin}) structured to guarantee strict segregation of concerns, end-to-end provenance tracking, and scientific reproducibility. The core package is organized into dedicated sub-packages:

\begin{itemize}
    \item \texttt{intellitwin.data}: Implements C-MAPSS dataset loaders, feature qualification routines, training-only z-score normalization in \texttt{preprocessing.py}, split handling in \texttt{splits.py}, and causal sliding window generators in \texttt{windowing.py} ($w=30$, stride 1, no padding). Enforces immutable engine-level partitioning based on pre-generated split manifests.
    \item \texttt{intellitwin.models}: Implements \texttt{sklearn.ensemble.HistGradientBoostingRegressor} in \texttt{gbr.py} and PyTorch recurrent Long Short-Term Memory networks in \texttt{lstm.py}. Metric functions in \texttt{metrics.py} compute uncapped RMSE, uncapped MAE, and capped RMSE (not the asymmetric score). Standardizes model serialization, inference pipelines, and CPU execution verification.
    \item \texttt{intellitwin.uncertainty}: Implements inductive split-conformal calibrators in \texttt{calibration.py}, exact rational engine-weighted quantile computation in \texttt{quantiles.py}, and asymmetric nonconformity scaling in \texttt{scores.py} ($\beta = -\ln 2$). Enforces deterministic fallback rules for regimes with insufficient engine counts ($m_g < \max(10, \lceil 1/\alpha \rceil - 1)$).
    \item \texttt{intellitwin.simulator}: Implements the discrete-event sequential maintenance simulator via \texttt{simulate\_engine\_trajectory} and \texttt{simulate\_fleet} in \texttt{engine.py}, with synthetic cost configuration governed by \texttt{MaintenanceCostConfig} and cost functions in \texttt{costs.py}.
    \item \texttt{intellitwin.decision}: Contains maintenance decision policies in \texttt{policies.py} ($L(t) \le 1.0$ cycle) and matched-conservatism control baseline generators in \texttt{controls.py}.
    \item \texttt{intellitwin.evaluation}: Contains cluster-bootstrap statistical inference in \texttt{bootstrap.py} (10,000 paired engine resamples), component and RQ decision rules in \texttt{decisions.py}, simulation-policy execution and repricing in \texttt{inference.py}, and evidence schema generators in \texttt{evidence\_schema.py}.
    \item \texttt{intellitwin.provenance}: Manages cryptographically verifiable SHA-256 artifact hashing, git commit tracking via \texttt{get\_git\_info}, and environment profiling via \texttt{capture\_environment\_metadata}.
\end{itemize}

\section{Registry Architecture and Frozen Artifacts}
To maintain strict governance over research artifacts, all model checkpoints, calibrator bundles, and experimental parameters are tracked via immutable JSON registries:
\begin{enumerate}
    \item \textbf{Base Model Registry} (\texttt{experiments/base\_models/model\_registry.json}): Catalogs the 30 base model checkpoints across 6 experimental cells (FD001, FD002, FD004 $\times$ GBR, LSTM) and 5 official seeds ($2026$--$2030$), including file paths, model architecture specifications, training metrics, and SHA-256 hashes.
    \item \textbf{Calibration Registry} (\texttt{experiments/calibration/calibration\_registry.json}): Documents 90 fitted conformal calibrator bundles covering global, regime-stratified, and decision-aware variants.
    \item \textbf{Selection Freeze} (\texttt{experiments/calibration/selection/selection\_freeze.json}): Records the hyperparameter configuration selected strictly on validation engine splits (\texttt{gamma2\_betam1}) and frozen prior to held-out test evaluation.
    \item \textbf{Protocol Freeze} (\texttt{experiments/pretest\_verification\_v4/protocol\_freeze.json}): Formally locks the evaluation parameters, cost constants, seed sequences, bootstrap sample counts ($10{,}000$), and decision thresholds for confirmatory testing.
    \item \textbf{Control Reconstruction} (\texttt{experiments/pretest\_verification\_v4/control\_selection.json}): Catalogs the exact selection parameters for the four prespecified matched-conservatism controls selected on FD002 validation engines across seeds 2026--2030.
\end{enumerate}

\section{Provenance Tracking and Auditability}
Every official experimental execution generates an audit record capturing stored fields precisely:
\begin{itemize}
    \item Timestamp in UTC ISO format (\texttt{timestamp\_utc});
    \item Python runtime version string (\texttt{python\_version}) and host OS platform string (\texttt{platform});
    \item Compute device indicator (\texttt{device}, defaulted strictly to \texttt{cpu});
    \item Core installed library versions: \texttt{numpy}, \texttt{pandas}, \texttt{scikit\_learn}, \texttt{torch}, and \texttt{pyyaml};
    \item Exact command arguments executed (\texttt{command\_args});
    \item Git commit SHA and working-tree dirty status;
    \item Input data file SHA-256 digests and output artifact checksums.
\end{itemize}
We do not claim that individual runs record CPU hardware model, physical memory capacity, a full lockfile, or full internal PRNG state.

\section{Demarcation of Implemented Modules vs. Planned UI}
To maintain rigorous scientific boundaries, we explicitly demarcate implemented research components from planned presentation features:
\begin{itemize}
    \item \textbf{Implemented Research Prototype}: All data ingestion, feature qualification, base model training, conformal calibration, discrete-event maintenance simulation, and bootstrap inference modules are fully implemented, tested, and audited in \texttt{src/intellitwin/}.
    \item \textbf{Planned Demonstrator UI}: An interactive web-based dashboard for replaying engine degradation trajectories and visualizing simulated fleet maintenance schedules is planned for final presentation integration (tracked under \texttt{UPD-06}). The demonstrator will operate strictly in offline replay mode and makes no claim of real-time physical engine telemetry integration or flight certification.
\end{itemize}
