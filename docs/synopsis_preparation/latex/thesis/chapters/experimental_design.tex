\chapter{Experimental Design and Confirmatory Protocol}
\label{chap:experimental_design}

\section{Benchmark Datasets and Stratification}
The empirical evaluation of IntelliTwin is conducted across three sub-datasets of the NASA C-MAPSS turbofan engine degradation benchmark \cite{saxena2008damage}:
\begin{enumerate}
    \item \textbf{FD001}: Single operating condition (sea level), single failure mode (high-pressure compressor degradation), comprising 100 complete run-to-failure engine units.
    \item \textbf{FD002}: Six operating flight conditions, single failure mode (HPC degradation), comprising 260 engine units.
    \item \textbf{FD004}: Six operating flight conditions, two concurrent failure modes (HPC and fan degradation), comprising 249 engine units.
\end{enumerate}

\section{Engine-Level Disjoint Partitioning}
To prevent data leakage across temporal cycles, engine trajectories are partitioned into disjoint splits using master seed $2026$ prior to any data preprocessing:
\begin{itemize}
    \item \textbf{FD001} (100 engines): 50 training (50\%), 20 calibration (20\%), 10 validation (10\%), and 20 held-out test engines (20\%).
    \item \textbf{FD002} (260 engines): 130 training (50\%), 52 calibration (20\%), 26 validation (10\%), and 52 held-out test engines (20\%), stratified across engine lifetime quartiles ($Q_1$--$Q_4$).
    \item \textbf{FD004} (249 engines): 124 training (50\%), 50 calibration (20\%), 25 validation (10\%), and 50 held-out test engines (20\%).
\end{itemize}
Across the complete benchmark suite, 304 engines are allocated to training, 122 to calibration, 61 to validation, and 122 to final held-out confirmatory evaluation (total 609 engines).

\section{Experimental Cells and Replications}
The experimental matrix comprises a $3 \times 2$ grid (6 experimental cells):
\begin{equation}
\{\text{FD001}, \text{FD002}, \text{FD004}\} \times \{\text{GBR}, \text{LSTM}\}.
\end{equation}
Two point-prediction architectures operate on identical 30-cycle causal horizons:
\begin{enumerate}
    \item \textbf{Gradient Boosted Regressor (GBR)}: \texttt{sklearn.ensemble.HistGradientBoostingRegressor} operating on C-order flattened $30 \times 17 = 510$-dimensional vectors. Selected configs: \texttt{gbr\_lr010\_leaf15\_l2\_0} (FD001) and \texttt{gbr\_lr010\_leaf31\_l2\_0} (FD002, FD004).
    \item \textbf{Long Short-Term Memory (LSTM)}: Single-layer unidirectional PyTorch LSTM ($H=64$, recurrent dropout $0.0$, followed by \texttt{nn.Dropout(p=0.20)} and \texttt{nn.Linear(64, 1)}, learning rate $\eta=0.0010$, \texttt{lstm\_h64\_lr0010}) with early stopping on validation uncapped RMSE.
\end{enumerate}
Each cell is trained across five pre-registered random seeds:
\begin{equation}
\mathcal{S} = \{2026, 2027, 2028, 2029, 2030\}.
\end{equation}
This produces 30 base model checkpoints and 90 conformal calibrator bundles. Two selection seeds (2026 and 2027) used during model development are distinguished from the five final model seeds. We do not characterize the five GBR seeds as independent experiments, nor assert universal deterministic behavior beyond the recorded runs.

\section{Matched-Conservatism Control Baselines}
To isolate the operational decision value of calibrated uncertainty from trivial policy over-conservatism (RQ3), we formulate four named controls across three distinct baseline families:
\begin{enumerate}
    \item \textbf{Matched-Width Interval Family (\texttt{matched\_width\_interval})}:
    Sources from \texttt{global\_hcp} or \texttt{regime\_hcp}, scaling unclipped half-width by $\lambda \in [0.01, 4.0]$ (plus $\{5, 6, 8, 12, 16\}$):
    \begin{align}
    q_{\text{source}}(t) &= U_{\text{source}}(t) - p(t) \\
    L_\lambda(t) &= \max(0, \; p(t) - \lambda q_{\text{source}}(t)), \quad U_\lambda(t) = p(t) + \lambda q_{\text{source}}(t)
    \end{align}
    Selected on FD002 validation data to minimize absolute difference from proposed validation MPIW (required $\le 1.0$ cycle): GBR selects \texttt{global\_hcp} with $\lambda=0.92$; LSTM selects \texttt{regime\_hcp} with $\lambda=0.90$.

    \item \textbf{Widened Interval Family (\texttt{widened\_interval})}:
    Same scaling formula with $\lambda \ge 1.00$, minimizing validation cost: GBR selects \texttt{regime\_hcp} with $\lambda=1.00$; LSTM selects \texttt{global\_hcp} with $\lambda=1.00$.

    \item \textbf{Point Safety Margin Family (\texttt{point\_safety\_margin})}:
    Maintains iff $p \le 1 + m$ for $m \in \{0, \dots, 250\}$, minimizing validation cost: GBR selects $m=5$; LSTM selects $m=4$. As a point policy, width and conformal coverage metrics are designated \texttt{NOT\_APPLICABLE}.

    \item \textbf{Earlier Fixed Policy Family (\texttt{earlier\_intervention})}:
    Maintains iff $L_{\text{source}} \le h$ for $h \in \{1, \dots, 251\}$, minimizing validation cost: GBR selects \texttt{regime\_hcp} with $h=1$; LSTM selects \texttt{global\_hcp} with $h=1$.
\end{enumerate}
All control selection executed on FD002 validation engines across seeds 2026--2030 under \texttt{primary\_reference} at 90\% coverage, completely isolated from calibration or held-out test data.

\section{Statistical Inference Protocol and Decision Rules}
Confirmatory hypothesis testing is executed strictly via paired engine-level cluster bootstrap resampling:
\begin{itemize}
    \item \textbf{Cluster Unit}: The independent statistical unit is the physical engine unit ($i \in \{1, \dots, N\}$). Individual cycles within an engine trajectory are never resampled independently. Seeds are averaged within engine clusters as descriptive training variability.
    \item \textbf{Bootstrap Replicates}: $B = 10{,}000$ paired bootstrap samples are drawn with replacement, stratified by engine lifetime quartiles ($Q_1$--$Q_4$), using \texttt{PCG64} PRNG with seed sequence \texttt{SeedSequence([2026, 6, dataset\_number])}.
    \item \textbf{Equal Engine Weighting}: All fleet metrics (coverage, width, cost, failure rate) are computed with equal weighting per engine unit.
    \item \textbf{Missing-Group Bound Propagation}: If an eligible subgroup ($\ge 10$ engines) is absent in a bootstrap resample, its absolute coverage error is bounded by $[0.0, 0.90]$ at 90\% nominal coverage and propagated conservatively.
    \item \textbf{Multiplicity Correction}: Family-wise error rate across RQ1--RQ4 is controlled via Bonferroni correction:
    \begin{equation}
    \alpha_{\text{conf}} = \frac{0.05}{4} = 0.0125.
    \end{equation}
    Confirmatory decision rules utilize $98.75\%$ two-sided percentile confidence intervals (empirical percentiles $0.625\%$ and $99.375\%$).
    \item \textbf{Intersection-Union Test (IUT)}: Benefit conditions pass if lower $\text{CI} > \text{margin}$; ceiling/noninferiority conditions pass if upper $\text{CI} < \text{ceiling}$. Equality with a boundary or degenerate inference is inconclusive. Failure safeguard uses observed fleet failure rates ($\Deltafail \le 0.0$). A hypothesis is decided as \textbf{Supported} iff all required criteria pass at the $98.75\%$ level, \textbf{Unsupported} if any required condition fails, and otherwise \textbf{Inconclusive}.
\end{itemize}
