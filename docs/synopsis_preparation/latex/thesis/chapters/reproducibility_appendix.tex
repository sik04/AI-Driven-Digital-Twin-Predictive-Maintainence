\section{Software Environment and Dependencies}
The framework defines declared package constraints via the \texttt{[project.optional-dependencies] research} extra in \texttt{pyproject.toml}:
\begin{itemize}
    \item \texttt{numpy} $\ge 1.24.0$;
    \item \texttt{pandas} $\ge 2.0.0$;
    \item \texttt{scikit-learn} $\ge 1.2.0$;
    \item \texttt{torch} $\ge 2.2$;
    \item \texttt{PyYAML} $\ge 6, < 7$.
\end{itemize}
Note that \texttt{lightgbm} is not a project dependency; base GBR predictors are implemented strictly via \texttt{sklearn.ensemble.HistGradientBoostingRegressor}.

We distinguish declared dependency constraints from recorded runtime environments and environments tested by automated Continuous Integration (CI). CI currently validates Python 3.10; universal compatibility across every unconstrained Python version $\ge 3.10$ is not claimed.

\section{Execution Commands and Audit Pipelines}
The repository provides verified scripts for auditing models and artifacts (verified via source inspection):
\begin{enumerate}
    \item \textbf{Data Pipeline Test Suite}:
\begin{verbatim}
pytest tests/test_data_pipeline.py
\end{verbatim}
    \item \textbf{Base Model Registry Audit}:
\begin{verbatim}
python scripts/audit_step07_base_models.py --reproduce-predictions
\end{verbatim}
    \item \textbf{Conformal Calibration Audit}:
\begin{verbatim}
python scripts/audit_step08_calibration.py
\end{verbatim}
    \item \textbf{Pre-Test Confirmatory Freeze Verification}:
\begin{verbatim}
python scripts/audit_step09_freeze.py
\end{verbatim}
    \item \textbf{Smoke Test Validation Execution}:
\begin{verbatim}
python scripts/run_step09_validation_smoke.py
\end{verbatim}
\end{enumerate}
