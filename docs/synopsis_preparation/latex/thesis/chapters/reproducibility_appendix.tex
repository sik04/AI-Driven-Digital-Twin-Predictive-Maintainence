\section{Software Environment and Dependencies}
The framework is verified on Python 3.10+ (64-bit). The production environment requires the following core dependencies:
\begin{itemize}
    \item \texttt{numpy} $\ge 1.24.0$ (backed by \texttt{PCG64} PRNG);
    \item \texttt{scipy} $\ge 1.10.0$;
    \item \texttt{pandas} $\ge 2.0.0$;
    \item \texttt{scikit-learn} $\ge 1.2.0$;
    \item \texttt{lightgbm} $\ge 4.0.0$;
    \item \texttt{torch} $\ge 2.0.0$;
    \item \texttt{pyyaml} $\ge 6.0$.
\end{itemize}

\section{Execution Commands and Audit Pipelines}
The repository includes automated execution and auditing scripts to verify data pipelines, model registries, and calibration bundles:
\begin{enumerate}
    \item \textbf{Data Pipeline Verification}:
\begin{verbatim}
python -m pytest tests/test_data_pipeline.py
\end{verbatim}
    \item \textbf{Base Model Registry Audit}:
\begin{verbatim}
python scripts/audit_step07_models.py
\end{verbatim}
    \item \textbf{Conformal Calibration Audit}:
\begin{verbatim}
python scripts/audit_step08_calibration.py
\end{verbatim}
    \item \textbf{Pre-Test Confirmatory Freeze Verification}:
\begin{verbatim}
python scripts/audit_step09_freeze.py
\end{verbatim}
    \item \textbf{Smoke Test Execution}:
\begin{verbatim}
python scripts/run_step09_validation_smoke.py
\end{verbatim}
\end{enumerate}
