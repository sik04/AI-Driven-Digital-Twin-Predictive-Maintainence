\chapter*{Abstract}
Predictive maintenance for safety-critical aviation assets requires balancing the catastrophic safety and financial hazards of unplanned in-flight engine failures against the economic waste of premature component retirement. Conventional prognostic models focus on minimizing cycle-level Remaining Useful Life (RUL) regression errors without quantifying predictive uncertainty or accommodating asymmetric maintenance loss functions.

In this work, we develop and formalize \textbf{IntelliTwin}, an end-to-end framework integrating data-driven degradation predictors (Gradient Boosted Regressors and recurrent Long Short-Term Memory networks) with hierarchical, decision-aware conformal prediction. The framework enforces strict engine-level disjoint data partitioning (304 training, 122 calibration, 61 validation, and 122 held-out test engines across NASA C-MAPSS sub-datasets FD001, FD002, and FD004), causal sliding temporal windows ($w=30$, stride 1), exact rational engine-weighted empirical quantiles, and condition-stratified conformal calibration with deterministic fallback rules. Nonconformity scoring incorporates an asymmetric loss parameter ($\beta = -\ln 2$) that penalizes dangerous RUL overestimation.

Downstream operational utility is evaluated through discrete-event fleet maintenance simulation. To determine whether observed cost benefits stem from calibrated uncertainty rather than simple over-conservatism, IntelliTwin is evaluated against four named controls across three baseline families (matched-width heuristic intervals, widened intervals, point safety margins, and earlier fixed interventions). Confirmatory hypothesis testing is governed by paired engine-level cluster bootstrap inference ($B = 10{,}000$) with prespecified practical-effect margins and nominal Bonferroni family-wise error rate control ($98.75\%$ confidence intervals).
