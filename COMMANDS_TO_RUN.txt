================================================================================
INTELLITWIN: STEP-BY-STEP COMMANDS TO RUN & DEMONSTRATE THE PROJECT
An AI-Driven Digital Twin Framework for Predictive Maintenance of Engineering Assets
Authors: Mayank Singh (ECE), Shiksha Pandey (IT), Ruchi Gupta (IT) @ AKGEC
================================================================================

Open PowerShell or Command Prompt inside the project directory:
cd "c:\Users\shiks\Downloads\res paper"

--------------------------------------------------------------------------------
STEP 1: INSTALL DEPENDENCIES
--------------------------------------------------------------------------------
Command 1:
pip install -r requirements.txt
pip install torch --extra-index-url https://download.pytorch.org/whl/cpu


--------------------------------------------------------------------------------
STEP 2: RUN THE INTERACTIVE FACTORY DASHBOARD & BACKEND API
--------------------------------------------------------------------------------
Command 2A (Start Flask REST API & Web Dashboard):
python intellitwin/api.py

Then open your browser to:
http://localhost:5000
(or open frontend/index.html directly in Chrome/Edge)

Features displayed:
- Factory Overview with Overall Health ring (87% Good, 8/10 active machines)
- Multi-Machine Selector:
  1. CNC Machine - 01 (Healthy, 94%)
  2. Robotic Arm - 02 (Caution, 72%)
  3. Conveyor Belt - 03 (Critical, 38%)
  4. Air Compressor - 04 (Healthy, 89%)
  5. Hydraulic Press - 05 (Caution, 65%)
- Selected Machine Detail Panel with 90% Conformal Confidence Bounds [28 - 44 hrs]
- Live telemetry parameters (Temperature, Vibration, Current, Speed, Load, Power)
- Real-time Chart.js degradation trends (Health score trend & Vibration trend)
- Maintenance history table and AI suggestion checklist with "Generate Report"


--------------------------------------------------------------------------------
STEP 3: TRAIN & EVALUATE MACHINE LEARNING MODELS ON NASA C-MAPSS
--------------------------------------------------------------------------------
Command 3:
Trains Heteroscedastic LSTM, GRU, Random Forest, XGBoost, and Isolation Forest
on 20,631 cycles from the NASA C-MAPSS FD001 dataset:
python -m intellitwin.train

Outputs generated:
- Model weights: intellitwin/models/lstm_rul.pt
- Empirical evaluation metrics: intellitwin/models/evaluation_results.json
  (RMSE 16.00, NASA score 542.1, 89.0% health accuracy, 95% conformal coverage,
   100% catastrophic failure prevention, 41.1 cycles mean lead time)


--------------------------------------------------------------------------------
STEP 4: GENERATE PUBLICATION-GRADE FIGURES (300 DPI)
--------------------------------------------------------------------------------
Command 4:
python intellitwin/generate_figures.py

Generates Figs 1-5 in figures/:
- Fig 1: C-MAPSS RUL Trajectory with 90% Conformal Prediction Intervals
- Fig 2: Decoupled Sensor Residuals Resolving the Masking Problem
- Fig 3: Health State Confusion Matrix & Conformal Reliability Curve
- Fig 4: Prognostic Benchmark Comparison (RMSE vs NASA Score)
- Fig 5: Catastrophic Early Warning Lead Time Distribution


--------------------------------------------------------------------------------
STEP 5: REBUILD IEEE RESEARCH PAPER (DOCX, HTML, PDF)
--------------------------------------------------------------------------------
Command 5A (Build IEEE Word Document):
python manuscript/generate_ieee_paper_docx.py
-> Generates manuscript/INTELLITWIN_RESEARCH_PAPER_IEEE_FORMAT.docx

Command 5B (Build IEEE Double-Column PDF via headless Chrome):
python manuscript/build_double_column_paper.py
-> Generates manuscript/INTELLITWIN_RESEARCH_PAPER_DOUBLE_COLUMN.pdf
-> Generates manuscript/research_paper_double_column.html


--------------------------------------------------------------------------------
STEP 6: RUN COMPREHENSIVE INTEGRITY & CONSISTENCY AUDIT
--------------------------------------------------------------------------------
Command 6:
python intellitwin/verify_consistency.py
-> Checks all dataset files, models, frontend assets, figures, and manuscripts.


--------------------------------------------------------------------------------
STEP 7: GENERATE JOURNAL SUBMISSION ZIP ARCHIVE
--------------------------------------------------------------------------------
Command 7:
python manuscript/package_submission.py
-> Generates manuscript/intellitwin_journal_submission_package.zip
