================================================================================
UQ-DT: STEP-BY-STEP COMMANDS TO RUN THE PROJECT
Uncertainty-Quantified Digital Twin Framework for Safety-Critical Infrastructure
================================================================================

Open PowerShell or Command Prompt inside the project directory:
cd "c:\www\AI-Driven-Digital-Twin-Predictive-Maintainence"

--------------------------------------------------------------------------------
STEP 1: INSTALL DEPENDENCIES
--------------------------------------------------------------------------------
Command 1:
pip install -r requirements.txt

(Optional) Install the package in editable mode:
pip install -e .


--------------------------------------------------------------------------------
STEP 2: RUN LIVE SENSOR TELEMETRY & UQ-DT PROGNOSTIC STREAM (RECOMMENDED FOR EVALUATOR)
--------------------------------------------------------------------------------
Command 2A (Live Cyber-Physical Sensor Stream with Real-Time Telemetry):
Simulates live streaming of all 4 physical sensors (Vibration, Strain, Temp, Acoustic)
arriving cycle-by-cycle, live feature extraction, calibrated RUL intervals, and safety dispatch:
python demo_live_sensor_stream.py --speed 0.04

Command 2B (Simulate Harsh Weather Shock / Out-of-Distribution Shift):
Simulates sudden +8.5 deg C heatwave and shows how epistemic uncertainty triggers early dispatch:
python demo_live_sensor_stream.py --ood --speed 0.04

Command 2C (Compact Diagnostic Inspector):
python demo_interactive_uq_dt.py --asset 0 --nominal


--------------------------------------------------------------------------------
STEP 3: RUN AUTOMATED UNIT TEST SUITE
--------------------------------------------------------------------------------
Command 3:
Runs all 10 unit tests validating data simulation, metrics, CQR conformal calibration,
uncertainty variance decomposition, and multi-asset fleet dispatch.
python -m unittest tests/test_uq_framework.py


--------------------------------------------------------------------------------
STEP 4: RUN MASTER BENCHMARK SUITE (MODELS & FIGURES)
--------------------------------------------------------------------------------
Command 4:
Trains heteroscedastic deep ensembles, pinball quantile models, and corpus baselines
across 13,126 telemetry points. Computes all scientific metrics (PICP, NMPIW, CWC,
Winkler score, RMSE) and generates all 5 publication-ready 300-DPI plots in figures/.
python -m uq_digital_twin.run_benchmarks


--------------------------------------------------------------------------------
STEP 5: GENERATE JOURNAL SUBMISSION BUNDLE (ZIP)
--------------------------------------------------------------------------------
Command 5:
Bundles the LaTeX manuscript (main.tex), BibTeX (references.bib), academic paper (MD),
all 5 figures, and documentation into a single zip archive ready for IEEE/Elsevier submission.
python manuscript/package_submission.py


--------------------------------------------------------------------------------

git status

git pull

git push
